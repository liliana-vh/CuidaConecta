# CuidaConecta

CuidaConecta es una aplicación móvil desarrollada en Flutter como parte del Proyecto de Título de Ingeniería en Computación e Informática de la Universidad Andrés Bello.

Su objetivo es facilitar la conexión entre personas que requieren servicios de cuidado y cuidadores, permitiendo gestionar información, publicar avisos de servicios y realizar solicitudes.

## Tecnologías utilizadas

- Flutter y Dart: desarrollo de la aplicación móvil.
- Firebase Authentication: autenticación de usuarios.
- Cloud Firestore: almacenamiento y consulta de información.
- Cloudinary: almacenamiento de imágenes y archivos multimedia.

## Funcionalidades principales actuales

- Registro e inicio de sesión de usuarios.
- Gestión de información de usuarios.
- Publicación y consulta de avisos de servicios de cuidadores.
- Creación y gestión de solicitudes de servicios.
- Carga de imágenes y archivos multimedia.
- simulación de pagso

## Requisitos previos

Para ejecutar el proyecto localmente se necesita:

- Flutter SDK y Dart SDK.
- Android Studio o un dispositivo Android para ejecutar la aplicación.
- Visual Studio Code (opcional, como entorno de desarrollo).
- Acceso a la configuración de Firebase utilizada por el proyecto.
- Configuración de Cloudinary para la carga de archivos.

## Instalación y ejecución

1. Clonar el repositorio:

   git clone https://github.com/liliana-vh/CuidaConecta.git

2. Ingresar a la carpeta del proyecto:

   cd cuida_conecta

3. Instalar las dependencias:

   flutter pub get

4. Ejecutar la aplicación en un dispositivo o emulador compatible:

   flutter run


## Estado del proyecto

CuidaConecta se encuentra en etapa de desarrollo como prototipo funcional móvil para fines académicos.
